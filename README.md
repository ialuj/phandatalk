# PhandaTalk

PhandaTalk é uma plataforma de comunicação construída com **Spring Boot**, **MySQL** e **Liquibase**, preparada para rodar via **Docker**. O projeto segue boas práticas de desenvolvimento, utilizando **JPA/Hibernate** para persistência e Liquibase para versionamento do banco de dados.

---

## Tecnologias

- **Backend:** Java, Spring Boot 4.0
- **Banco de dados:** MySQL 8.1
- **Migrações:** Liquibase
- **Containerização:** Docker e Docker Compose
- **ORM:** Hibernate (JPA)
- **Controle de versão de mudanças no DB:** Liquibase XML

---

## Pré-requisitos

- Docker 20+
- Docker Compose 1.29+
- Java 17+
- Maven 3+
